YOUR DOCS - Android app project
================================

Phone par install karne ke liye APK chahiye. Do aasan tareeqe:

TAREEQA 1 - GitHub se (computer par kuch install nahi karna)
 1. github.com par free account banayein, "New repository" banayein (naam: YourDocs).
 2. Is poore folder ki saari files (".github" folder samet) us repository mein upload karein.
    (Add file > Upload files, phir folders drag karein. ".github" folder zaroor ho.)
 3. Repository ke "Actions" tab mein "Build APK" chalta nazar aayega (5-8 minute).
 4. Khatam hone par us run par click karein, neeche "Artifacts" mein "YourDocs-apk" download karein.
 5. Zip kholein, "app-debug.apk" phone mein bhej kar install karein
    (Settings mein "Install unknown apps" allow karna pad sakta hai).

TAREEQA 2 - Android Studio se
 1. Android Studio install karein, "Open" se yeh folder kholein.
 2. Build > Build Bundle(s) / APK(s) > Build APK(s).
 3. APK app/build/outputs/apk/debug/app-debug.apk mein milegi.
